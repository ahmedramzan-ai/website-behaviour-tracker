# Website Behaviour Tracker

This project tracks how users interact with a webpage. I built it to explore how clicks, mouse movement, and scrolling can be recorded and visualized.

## Features

* Click heatmap
* Click scatter plot
* Mouse movement tracking
* Scroll depth tracking
* Click and interaction statistics
* Event log
* Element visibility tracking
* Export tracking data as JSON

## How to Run

1. Download the HTML file from this repository.
2. Open it in your browser.
3. Start tracking and interact with the webpage.
4. Use the available controls to view the results and export the data.
